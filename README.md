# Levántate Lázaro

*Arise, Lazarus: resurrect your dead repos.*

Every developer has a repo they abandoned. Lack of time, money or knowledge stopped it. Lázaro reads the Git history, rebuilds what the project was meant to be, fixes the first blocker and proves the fix with a local check.

**Kiroween 2026 category:** Resurrection. We revive abandoned code and obsolete tech.

## How it works

A guide agent (Lázaro) talks to you. Four specialists work behind it.

| Agent | Job | Can edit code |
| --- | --- | --- |
| Lázaro (guide) | Talks to you, asks what it needs, asks permission | No |
| Forense | Reads Git history and finds evidence | No |
| Arquitecto | Writes the route to "done" | Specs only |
| Obrero | Applies one approved task | Yes, approved files only |
| Verificador | Runs the agreed check | No |

The agent that fixes is never the agent that verifies.
